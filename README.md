# Lux Mods

**Um Minecraft mais vivo, sem deixar de ser Minecraft.**

Lux Mods é um ecossistema planejado de módulos para Minecraft Java: exploração cinematográfica, NPCs com diálogos contextuais, vilas com moradores e propriedades, quests opcionais, progressão RPG, interface limpa, mochilas e itens personalizados.

> **Estado:** pré-produção / documentação. Nenhum módulo jogável foi implementado neste repositório ainda.

## Stack candidata (a validar no primeiro protótipo)

Minecraft Java **1.21.1**, NeoForge, Java **21**, Gradle, repositório com módulos independentes. O **Lux Studio** é uma ferramenta web separada. Nenhuma versão de API/loader está travada antes do *spike* técnico.

## Princípio essencial

O mundo existe sem esperar o jogador. Diálogos revelam histórias; nem toda história é uma missão. O jogador pode explorar livremente, configurar sua interface e instalar somente os módulos desejados.

**Projeto privado em planejamento — distribuição, licenças e identidade visual ainda por definir.**
