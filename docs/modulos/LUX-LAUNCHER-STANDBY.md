# Lux Launcher — Ideia futura, em standby

Um launcher personalizado que instala/atualiza modpacks e oferece branding Lux Mods seria interessante, mas não é necessário para validar o gameplay. Prioridade é usar SKLauncher/Prism Launcher ou outra ferramenta de desenvolvimento suportada para rodar instâncias.

Se reavaliado futuramente: autenticação oficial Microsoft e verificação de posse de Minecraft, respeitar EULA e regras de redistribuição, gerenciamento de Java, versão, NeoForge, cache, updates, assinatura/hash, rollback e preservação de mundos. Não redistribuir Minecraft nem dependências sem permissão.

**Decisão atual:** NÃO implementar nesta fase.
